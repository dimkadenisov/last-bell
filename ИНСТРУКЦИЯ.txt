       WATERMARK REMOVER - PUPPETEER AUTOMATION

Здравствуйте! Я создал полностью автоматизированный скрипт для
удаления водяных знаков из ваших фотографий.

📝 ЧТО НУЖНО СДЕЛАТЬ:

1. УСТАНОВИТЕ ЗАВИСИМОСТИ (первый раз):

   Откройте терминал и выполните:

   cd ~/Downloads/photo
   npm install

2. ЗАПУСТИТЕ СКРИПТ:

   node watermark-remover.js

3. ОЖИДАЙТЕ РЕЗУЛЬТАТОВ:

   - Откроется браузер Chrome
   - Скрипт будет обрабатывать фотографии одну за одной
   - Результаты сохранятся в папке: ~/Downloads/photo/clean/

═══════════════════════════════════════════════════════════════

🔧 ТРЕБОВАНИЯ:

✓ Node.js 16+ (https://nodejs.org)
✓ Google Chrome браузер (https://www.google.com/chrome)
✓ npm (идёт вместе с Node.js)

═══════════════════════════════════════════════════════════════

📂 СТРУКТУРА ПРОЕКТА:

photo/
├── watermark-remover.js    ← Скрипт (готов к запуску!)
├── package.json            ← Зависимости
├── README.md               ← Подробная документация
├── clean/                  ← Результаты (создаётся автоматически)
└── DSC00892.jpg, DSC00896.jpg, ... ← Ваши фотографии

═══════════════════════════════════════════════════════════════

⚙️ КАСТОМИЗАЦИЯ:

Если хотите обработать больше/меньше фотографий, отредактируйте
строку в watermark-remover.js:

    getPhotoFiles(3)  ← Измените число (3 = 3 фотографии)

Для обработки всех фотографий в папке:

    getPhotoFiles(Infinity)

═══════════════════════════════════════════════════════════════

🐛 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ:

1. Chrome не найдена?
   - Установите Google Chrome с https://www.google.com/chrome
   - Или установите переменную CHROME_PATH

2. npm install не работает?
   - Убедитесь что Node.js правильно установлен
   - Запустите: npm --version

3. Файлы не скачиваются?
   - Проверьте что папка clean/ существует и доступна
   - Проверьте настройки браузера для скачиваний

✅ ВСЁ ГОТОВО!

Просто откройте терминал в папке ~/Downloads/photo и запустите:

    node watermark-remover.js

Браузер откроется автоматически и начнёт обработку фотографий.
